# Contributing

Thanks for taking an interest. This is a personal project, so the most useful contributions are:

- **Bug reports**, especially figures that look wrong. The app's URL holds the whole selection, so pasting it usually reproduces the problem.
- **Ideas** from people who do road-safety work: analyses you need, methods the app should follow, or data sources it should use.

Open an [issue](https://github.com/benw312/stats19-explorer/issues/new/choose) for either. Security problems go through [SECURITY.md](SECURITY.md) instead.

## Pull requests

This repository is published from a private development repository, so pull requests can't be merged here directly. They're still welcome: a change that fits will be applied by hand and credited to you in the commit. Please open an issue first for anything bigger than a small fix, so we can agree the approach.

By contributing, you agree that your contribution is licensed under the project's [AGPL-3.0 licence](LICENSE).

## Running the checks

See [Tests](README.md#tests) in the README. CI runs the same lint, unit and PostGIS integration tests, and the web build, on every push.
